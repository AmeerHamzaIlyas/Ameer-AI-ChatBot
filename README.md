#  Ameer AI ChatBot

 A smart, sleek, and adaptable AI co-pilot designed to think, code, and strategize with you — powered by Google Gemini.
 Why Ameer AI?

Most AI chat interfaces feel static and generic. **Ameer AI ChatBot** was built to change that. It gives you a personalized workspace where you can switch AI personas on the fly — whether you need deep architectural code reviews, empirical data analysis, creative storytelling, or executive decision memos.
Built with a lightweight vanilla frontend and an asynchronous Python backend using the official `google-genai` SDK, it delivers ultra-fast responses without heavy frameworks or unnecessary bloat.

Features That Matter

Tailored Personas: Choose how your AI speaks:
Software Architect: Code-first, clean patterns, distributed systems.
Research Analyst: Quantitative breakdowns, hypothesis validation, statistics.
Creative Strategist: Compelling messaging, product intuition, and UX concepts.
Autonomous Executive: Prioritized roadmaps, actionable memos, and clarity.
Powered by Gemini Flash: Fast latency and up-to-date reasoning using Google's latest multimodal models.
Glassmorphism UI: Modern dark mode with subtle neon gradients, ambient glow, and micro-animations.
Mobile Responsive: Works seamlessly on phones, tablets, and desktop screens alike.
Secure by Default: Secrets stay private — API keys are managed securely via `.env` and environment variables.


##  Tech Stack

Frontend: HTML5, Modern Vanilla CSS (Glassmorphism & Flex/Grid), JavaScript (ES6+)
Backend: Python 3 (`http.server`, native REST handler)
AI Engine: Google Gemini API via official `google-genai` SDK
Fonts & Styling: Inter, Outfit, JetBrains Mono
